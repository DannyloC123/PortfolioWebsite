> Self-hosted infrastructure, networking, and automation platform

Project Overview

Built and maintain a self-hosted server environment designed to support media streaming, game servers, remote access, automation services, and future AI workloads. The system uses multiple Linux machines connected through a local network and runs most services through Docker containers.

The project began as a way to centralize personal services and evolved into a hands-on environment for learning systems administration, networking, containerization, service deployment, and troubleshooting across multiple machines.

Infrastructure

The server environment consists of multiple Linux-based nodes connected through a dedicated network. Services are deployed using Docker and configured to run continuously with persistent storage, automatic restarts, and remote management.

  • Ubuntu Linux server environment
  • Multi-machine network architecture
  • Docker-based service deployment
  • Persistent volumes and container configuration
  • SSH-based remote administration
  • Network routing and port forwarding

Services

The infrastructure hosts a variety of self-managed applications ranging from media services to multiplayer game servers and custom automation tools.

  • Jellyfin media server for movies and television
  • Minecraft Bedrock dedicated server
  • Satisfactory dedicated server
  • WireGuard VPN for secure remote access
  • Custom Discord-based automation services
  • Traffic monitoring and notification tools
  • Calendar automation services

Networking & Remote Access

Remote access is handled through a self-hosted WireGuard VPN, allowing devices outside the home network to securely access internal services. The setup also required configuring port forwarding, network interfaces, SSH access, and troubleshooting connectivity across different networks.

  • WireGuard VPN configuration
  • Secure remote service access
  • Router port forwarding
  • Local network troubleshooting
  • SSH key and remote shell management

Purpose

This project serves as both a personal infrastructure platform and a practical systems engineering environment. It provides hands-on experience managing long-running services, debugging networking issues, deploying containerized applications, and maintaining systems that need to remain available and reliable over time.
