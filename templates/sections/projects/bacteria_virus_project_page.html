Bacteria-Virus Ecosystem

> Interactive predator-prey simulation with evolving agents

Project Overview

Built an interactive ecosystem simulation in Python with Pygame featuring bacteria, viruses, and food pellets. Each entity follows simple behavioral rules that combine to create predator-prey dynamics over time.

Bacteria search for food while attempting to avoid nearby viruses. Viruses actively pursue bacteria, and both organisms lose health as time passes and as they move through the environment.

Agent Behavior

  • Bacteria locate nearby food pellets and move toward them
  • Bacteria detect nearby viruses and attempt to flee
  • Viruses search for and pursue the nearest bacteria
  • Random movement is used when no meaningful target is available
  • Collision detection controls feeding interactions

Health & Survival

Every organism has a health value that decreases through movement and survival costs. Bacteria restore health by consuming food pellets, while viruses survive by consuming bacteria.

  • Health decay over time and movement
  • Food-based health recovery
  • Predator-prey collision logic
  • Population limits to prevent uncontrolled growth

Reproduction & Evolution

Organisms can reproduce after reaching the required health state and completing a reproduction cooldown. New bacteria can inherit slightly mutated movement speeds, allowing simple evolutionary behavior to emerge across generations.

  • Reproduction cooldown system
  • Health-based reproduction requirements
  • Random speed mutation in offspring
  • Dynamic population growth and decline

Technical Design

  • Object-oriented entity system
  • Pygame rendering and event loop
  • Vector normalization for directional movement
  • Nearest-target search for agent decision making
  • Distance-based collision detection
  • Custom image assets for bacteria and viruses

Purpose

This project explores how relatively simple rules can create complex system-level behavior. It combines simulation design, object-oriented programming, real-time graphics, and basic agent decision-making in a visual environment.
