Product Review NLP Analysis

> Sentiment analysis, semantic clustering, and product theme extraction

Project Overview

Built an NLP pipeline for analyzing large collections of consumer product reviews and extracting useful information about sentiment, customer concerns, and recurring product attributes.

The project combines supervised sentiment classification, semantic text embeddings, unsupervised clustering, TF-IDF keyword extraction, and data visualization to transform raw review text into interpretable themes.

NLP Pipeline

  • Sentiment classification using a pretrained DistilBERT SST-2 model
  • Sentence embeddings generated with all-MiniLM-L6-v2
  • KMeans clustering to group semantically similar reviews
  • Silhouette score evaluation for clustering quality
  • TF-IDF keyword extraction for cluster interpretation
  • Part-of-speech filtering to surface descriptive nouns and adjectives

Data Processing

Review ratings were converted into binary ground-truth sentiment labels, with ratings of 4–5 treated as positive and ratings of 1–2 treated as negative. Neutral 3-star reviews were excluded from the sentiment evaluation.

To make repeated experimentation faster, sentence embeddings were cached to disk instead of being regenerated on every run.

Theme Extraction

After clustering semantically similar reviews, TF-IDF was used to identify representative keywords for each cluster. Custom stopword filtering and part-of-speech tagging removed brand names, generic sentiment words, and other low-information terms.

  • Human-readable attribute labels such as scent, value, and cleaning effectiveness
  • Higher-level grouping of related product themes
  • Cluster performance comparison using review ratings and sentiment
  • Visualization of product themes and review trends

Tools & Deployment

  • Python, pandas, PyTorch, scikit-learn, NLTK, and Hugging Face Transformers
  • Excel and CSV-based review datasets
  • Cached embedding and TF-IDF artifacts for faster iteration
  • Dockerized execution environment for reproducibility

Purpose

The project demonstrates how machine learning and NLP can turn large volumes of unstructured customer feedback into structured insights that can support product analysis and decision-making.
